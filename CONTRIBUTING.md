# Contributing Guidelines

Thanks for helping make Hookstest better. This repo is intentionally small and focused, so contributions should stay lightweight and easy to review.

## What To Contribute
- Small, focused improvements to documentation.
- New hook examples that are easy to understand.
- Tiny scripts or samples that help explain hook behavior.

If you are unsure, open an issue to discuss the idea first.

## How To Contribute
1. Fork the repo and create a branch with a short, descriptive name.
2. Keep changes minimal and scoped to one idea.
3. Test any scripts locally before you open a PR.
4. Open a pull request and briefly explain what you changed and why.

## Style And Scope
- Prefer clarity over cleverness.
- Keep scripts portable and avoid unnecessary dependencies.
- Avoid large refactors or repo-wide changes unless discussed first.

## Need Help?
Open an issue with a clear description of your goal or question and we will take a look.
